## Known Risks
| Risk | Impact | Mitigation |
|---|---|---|
| AI chatbot hallucinating products not in catalog | Trust/UX damage | Ground responses strictly via pgvector retrieval + function calling, never free-form product claims |
| Scope creep — trying to build too many modules per phase | Broken/incomplete code | Enforce one-phase-at-a-time workflow (ImplementationPlan.md) |
| Payment placeholder forgotten and shipped as "real" | Financial/trust risk | "Test Mode" label enforced in Design.md + Rules.md; explicit go-live checklist item before removing label |
| Farmer-facing UI too complex for target users | Low adoption by farmers | Dedicated simplified Farmer Centre UI (Phase 9), voice-assisted listing |
